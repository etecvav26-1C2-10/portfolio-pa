Exercícios do 2º Bimestre (C++ → Python)

## Sobre

Esta pasta contém os exercícios do **2º bimestre** convertidos de **C++ para Python**.

O objetivo é manter a mesma lógica dos programas originais, adaptando apenas a sintaxe para a linguagem Python, como parte dos estudos de programação

## Tecnologias

* **Linguagem original:** C++
* **Linguagem convertida:** Python 

Desenvolvido para a disciplina de **Desenvolvimento de Sistemas** — 2º Bimestre.
